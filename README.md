https://fjgarciahurtado.github.io/ai-library-site/

| Folder | Holds |
|---|---|
| `digest/` | Daily digests and weekly summaries |
| `topics/` | Long-lived topic pages |
| `sources/` | One note per captured article, paper, repo or release |
| `assets/` | Files the notes link to |

lost. Every commit mirrors a commit in the private library repository.
