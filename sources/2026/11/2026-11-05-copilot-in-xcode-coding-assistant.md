## Summary

Since 2026-11-04, GitHub Copilot can be chosen as a provider inside Xcode's built-in
coding assistant, in public preview. The separate "GitHub Copilot for Xcode" extension
remains available.

## Key points

- **Requirements:** Xcode 27.3 beta (Apple Developer Downloads), macOS Tahoe 26.6 or
  later, and any Copilot plan.
- **Enable it:** Xcode > Settings > Intelligence, then set up GitHub Copilot in the coding
  assistant.
- The changelog does not say which models are offered or whether Copilot's agent mode
  works through Xcode's assistant.

## Why it matters

Apple's IDE now hosts third-party coding assistants natively, so Copilot users on Apple
platforms no longer need a separate extension. It is one more sign that IDEs are becoming
hosts for several agent providers rather than shipping one.
