## Summary

Claude Code 2.1.332 (published 2026-11-25, 01:32 UTC) is a large release of about 150
changes. The headline additions are skills served by MCP servers (beta) and a new
`PreSkillShellCommand` hook event. Most of the rest is fixes: hangs and freezes, auto-
compaction, Code Mode, cloud-provider model resolution, and about 40 VS Code changes.
This note was written from the release feed; the individual items were read in grouped
form, not one by one.

## Key points

- **Skills from MCP servers (beta):** an MCP server can now provide skills. They show up
  as `server:skill`, next to local and plugin skills. Nothing to enable on the client
  side beyond updating; the server has to publish them.
- **`PreSkillShellCommand` hook:** a new hook event that fires before a skill runs a
  shell command, so you can log, allow, or block what skills execute. Configure it like
  other hooks in `settings.json`.
- **Held messages:** an "Always deliver" option for messages from other sessions that
  would otherwise be held for review.
- **Telemetry:** a new OpenTelemetry `assistant_response` event. `tool_input` for
  SendUserMessage now records only the text length unless `OTEL_LOG_ASSISTANT_RESPONSES=1`.
  The desktop Code tab reports `service.name` as `claude-code-desktop`.
- **Models on cloud providers:** Sonnet 5.5 and Opus 5.5 become defaults or aliases on
  some providers; the `sonnet` alias on Bedrock Mantle now means Sonnet 5; Foundry
  Sonnet 4, Opus 4, and Opus 4.1 are marked retired.
- **Reliability:** fixes for freezes on named pipes, hooks with endless output, MCP
  servers that flood stdout, `/stats` on large transcripts, and several auto-compaction
  cut-offs. Voice dictation now waits 60 seconds without speech (10 minutes overall).
- `claude auth login` exits with code 1 when a claude.ai login cannot be saved, which
  helps scripts.
- **Agent SDK:** the TypeScript Agent SDK v0.3.332 (same day) exposes the
  `PreSkillShellCommand` hook types, adds `tool_result_meta[].rewritten_by_plugin`, and
  makes `Query.setPermissionMode()` resolve with `{ mode }` (code typed as
  `Promise<void>` must change).
- Update with `claude update`.

## Why it matters

Skills served by MCP servers mean a team can ship skills next to its tools from one
server instead of distributing plugin folders. The new hook gives a control point over
what skills run in the shell, which matters as more third-party skills get installed.
