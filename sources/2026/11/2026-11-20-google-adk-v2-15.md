## Summary

ADK 2.15.0 makes live (voice) agents keep talking while slow tools run, adds pass@k
metrics to evaluation, and broadens artifact storage across cloud filesystems. It also
removes the Visual Agent Builder from ADK Web and turns on dynamic instruction routing
by default.

## Key points

- **Live agents:** `run_live` runs every tool call in a background task, so audio and
  barge-ins continue during slow tools. `send_context_update` changes the system
  instruction or tools mid-session on Gemini 3.x Live connections.
- **Evaluation:** `pass_at_k` and `pass_hat_k` in `multi_run_config`; `adk eval` prints a
  per-case multi-run summary and saves `.evalset_result.json`. New
  `tool_parameter_match` criterion gives partial credit per tool argument.
- **Storage:** `FsspecArtifactService` writes, deletes, and versions artifacts on
  `gs://`, `s3://`, `file://` and `memory://`. Experimental `BufferedSessionService`
  batches session events in the background.
- **Tools:** `GoogleMapsToolset` (Street View image, address validation, reverse
  geocoding); RAG memory search up to 6x faster.
- **Breaking:** the Visual Agent Builder is gone from ADK Web (use `adk create` or a
  coding agent); `McpInstructionProvider` no longer fills prompt arguments from
  `session.state` (pass `arguments=`). `DYNAMIC_INSTRUCTION_ROUTING` is on by default;
  opt out with `ADK_DISABLE_DYNAMIC_INSTRUCTION_ROUTING=1`.
- Upgrade: `pip install -U google-adk`.

## Why it matters

pass@k and per-argument tool scoring make ADK's built-in evals more useful for
non-deterministic agents, and non-blocking tools fix a common complaint with voice
agents.
