## Summary

Claude Code 2.1.323 (2026-11-12) adds Code Mode, an experimental opt-in in which Claude
writes JavaScript that calls its tools instead of calling them one at a time. Plugins can
now declare which Claude Code versions they support, `claude plugin validate` type-checks
TypeScript hook modules, and long-running hooks send a heartbeat in headless sessions. The
release also has a long list of permission and sandbox fixes.

## Key points

- **Code Mode (experimental, opt-in):** Claude writes JavaScript to call its tools. The
  release notes point to `https://code.claude.com/docs/en/code-mode` for turning it on, or
  off for an organization; that page returned 404 on 2026-11-13, so the setting name is
  not yet known. The idea is the same as "code execution with MCP": chaining tool calls
  in code keeps intermediate results out of the context window.
- **Plugin version ranges:** `engines["claude-code"]` in `plugin.json` keeps a plugin
  from being installed, updated, or loaded outside its stated range; install and update
  pick the newest plugin version that fits.
- **Plugin validation:** `claude plugin validate` type-checks a plugin's TypeScript hooks
  module (warnings; `--strict` fails on them). A plugin's `agent` setting is deprecated
  and now warns. `claude plugin install --json` reports `unsetOptionCount`.
- **Hooks:** a progress heartbeat every 30 seconds while hooks run long in `claude -p` and
  SDK sessions, so hosts do not treat the turn as hung. If a permission check errors
  after a `PreToolUse` hook said "allow", Claude Code now decides as if no hook answered.
- **Security fixes:** wildcard Bash allow rules such as `Bash(ls*)` could skip prompts;
  deny rules missed commands run through `sudo` and `env`; Write and Edit could write to a
  path covered by a `Read` deny rule; the sandbox could switch off mid-session;
  `--permission-mode auto` could start in a looser mode when auto mode was unavailable
  (it now starts in Manual). A startup warning flags allow rules with `*` in a variable
  value, such as `Bash(PORT=* npm run dev)`.
- **Context:** an unrecognised model ID is now assumed to have a 1M context window (was
  200K); set `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` for smaller third-party models.
- **Other:** `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1` turns off subagent progress
  summaries; the VS Code extension adds a workspace trust prompt and live Bash output.
- Update with `claude update`.

## Why it matters

Code Mode is a new way of running tools inside Claude Code itself and may cut token use
on tool-heavy tasks. Plugin authors get version pinning and type checks. The permission
fixes make it worth updating promptly, especially for anyone using wildcard allow rules.
