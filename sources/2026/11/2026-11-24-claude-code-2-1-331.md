## Summary

Claude Code 2.1.331 brings Code Mode to terminal sessions on the cloud providers, adds
an API connectivity check to `claude doctor`, and lets plugin manifests declare
optional dependencies. Most of the release is fixes: hanging MCP calls, hooks that
missed the last reply, and many VS Code extension bugs. The changelog heading has no
date. The date above is taken from the matching Agent SDK release (TypeScript v0.3.331,
2026-11-23).

## Key points

- **Code Mode on cloud providers:** Code Mode now works in terminal sessions on Amazon
  Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS.
- **`claude doctor` checks the API:** a new section shows whether the API is reachable,
  the HTTP status or error, or why it was not tested. This is the first thing to run
  when a proxy or gateway setup fails.
- **Proxies:** set `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION=1` if a proxy cuts off
  compressed responses. The changelog does not yet advise it for self-hosted runners
  or Remote Control.
- **Plugins:** manifests accept `optionalDependencies`, so you can disable or uninstall
  a dependency plugin on its own. The auto-update notice now names new dependency
  plugins.
- **Hooks:** Stop hooks in Claude Desktop now get the last reply, and SubagentStop hooks
  wait for it. A `PermissionDenied` hook's `retry: true` now retries only if the user
  asked for that call.
- **MCP:** tool calls no longer hang for up to 30 minutes on some malformed replies.
  Code Mode tool search shows more of each MCP tool's description.
- **Telemetry:** `claude_code.llm_request` spans carry the OpenTelemetry `gen_ai.usage.*`,
  `gen_ai.response.model`, and `gen_ai.operation.name` attributes. Input tokens include
  prompt-cache tokens.
- **Coming change:** from a release on or after 2026-11-30, managed
  `extraKnownMarketplaces` auto-update by default. Add `"autoUpdate": false` to an entry
  to opt out.
- **VS Code:** adds "Fix with Claude Code" quick fixes and test-failure actions, "Add to
  Chat" in Source Control, "Resolve Merge Conflicts" for conflicted files, and "Add Cell
  to Chat" for notebooks. Wrappers, hooks, or MCP servers that run VS Code as Node must
  now set `ELECTRON_RUN_AS_NODE=1`.
- `@file#10-12` now attaches only those lines again, and a reply that goes silent while
  thinking is retried once instead of failing.
- Update with `claude update`.

## Why it matters

`claude doctor` and the compression switch make gateway and proxy setups easier to
debug. Optional plugin dependencies and the coming marketplace auto-update matter to
anyone who manages plugins for a team.
