## Summary

Codex CLI 0.171.0 adds GPT-6.2 Sol and Astra to its model catalogue (Sol is the
default), turns on the TUI workspace by default, and lets `codex exec` run against an
existing app server. It also adds remote-control commands and a custom MCP-driven
status line.

## Key points

- **Models:** GPT-6.2 Sol and GPT-6.2 Astra are selectable; Sol is the default catalogue
  choice.
- **Workspace on by default:** the TUI shows searchable document previews, image
  previews, and subagent transcripts beside the main conversation.
- **Remote headless runs:** `codex exec --remote <ADDR>` starts or resumes a
  non-interactive session on an app server that is already running, which suits
  scripts and CI that should reuse one long-lived server.
- **Remote control:** `/rc` (or `/remote`) in the TUI manages local remote control and
  shows the device pairing code.
- **Status line:** `/statusline` can pick and author a custom MCP-backed status line
  when `tui_extensions_statusline` is enabled in config.
- Configurable undo and redo shortcuts in the (non-Vim) prompt composer.
- Install or update: `npm install -g @openai/codex` (or `brew upgrade codex`).

## Why it matters

Codex users get the new GPT-6.2 models by default without config changes, and
`codex exec --remote` makes Codex easier to drive from automation alongside an
interactive session.
