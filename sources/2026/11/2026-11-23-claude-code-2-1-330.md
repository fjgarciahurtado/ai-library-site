## Summary

Claude Code 2.1.330 (published 2026-11-20 at 22:32 UTC, after the previous digest) lets
recurring scheduled tasks and `/loop` run for up to 30 days instead of 7. It adds Easel,
a built-in mod that draws charts in the session, and makes enterprise sign-in apply the
organization's settings and cloud provider automatically. The VS Code extension gains
`/fork` and `/workflows`. Most of the roughly 100 other bullets are fixes. The details
come from the releases feed; the CHANGELOG page could not be read.

## Key points

- **Longer schedules:** recurring scheduled tasks and `/loop` now run up to 30 days
  (was 7). Nothing to enable; existing loops get the longer limit.
- **Easel charts:** a built-in mod that draws charts on Pro, Max, and (where available)
  Team and Enterprise plans, on macOS and Linux. To stop automatic charts, turn them off
  in `/config`.
- **Enterprise sign-in:** after `claude auth login`, Claude Code applies the
  organization's settings and uses its cloud provider or gateway.
  `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` prints the whole sign-in link (handy over SSH).
- **VS Code:** `/fork` and `/workflows` commands, plus settings
  `claudeCode.escapeStopsClaude`, `claudeCode.pinPrompt`, and
  `claudeCode.contextUsageThreshold`.
- **Self-hosted runners:** `--start-dir` (or `SELF_HOSTED_RUNNER_START_DIR`) starts work
  in a subfolder of a repository; two new `/metrics` series measure time from order to
  registration and to first session.
- **Changes to watch:** `claude --teleport` may print git commands instead of running
  them (with `-p` it exits 1 until you switch); `--hook-concurrency` sets spawn-runner
  hook concurrency per orchestrator (default 4); `bashEditDiffEnabled` in managed
  settings restores diffs for every Bash edit; `claude plugin install --json` reports
  `commandPrinted` and `commandFailed`.

## Why it matters

The 30-day limit makes `/loop` and scheduled tasks usable for week-long monitoring jobs
without re-creating them, and Easel brings inline charts into terminal sessions.
