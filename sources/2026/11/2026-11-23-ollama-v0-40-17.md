## Summary

Ollama 0.40.17 adds Thinking Machines' Inkling 2 Mini (Apple silicon only for now). It
makes `ollama launch claude` support Claude Code's deferred tool loading, and it serves
several requests at once on Apple silicon. The releases feed timestamps it 2026-11-21
04:05 UTC. The release page shows "10 Nov" without a year, which may be when the draft
was created, so the date is uncertain.

## Key points

- **New model:** `ollama run inkling-2-mini`, from Thinking Machines.
  - 26B total and 5.4B active parameters; about 20 GB on a Mac.
  - Handles text, images, tool calls, and thinking; reports 79.2% on SWE-bench
    Verified (vendor figure).
  - Apple silicon only in this release; PC support is promised. No licence is stated.
- **Deferred tools in Claude Code:** `ollama launch claude` now supports Claude Code's
  deferred tool loading, so MCP tools load only when needed. This saves context when
  you run Claude Code against local models.
- **Other launch changes:**
  - `ollama launch opencode` sets thinking options from model metadata.
  - `ollama launch pi` refreshes its model list after sign-in.
  - `ollama launch chatgpt --restore` keeps your existing settings and history.
- **Serving:** Apple silicon now serves multiple requests at once, and changing the
  context shift setting no longer reloads the model.
- **Fixes:** Vulkan uses mmap on integrated GPUs, which fixes the "Failed to allocate
  pinned memory" error. Disabling thinking now maps to the model's lowest reasoning
  level.

## Why it matters

Deferred tool loading was the main context cost of running Claude Code with many MCP
servers on a small local model. Ollama now supports it.
