## Summary

LlamaIndex 0.14.26 (2026-11-13) is the first release since 0.14.25 on 2026-09-21. It is
a maintenance release: it raises the minimum Python version of almost every integration
package for security fixes, and adds current Claude 5.5 and GPT-6 models to the Anthropic,
Bedrock, and OpenAI integrations. There is still no 0.15 or 1.0.

## Key points

- **Breaking:** nearly all integration packages raise their `requires-python` floor for
  security fixes (#24040); check your Python version before upgrading.
- **Models:** `llms-anthropic` 0.12.3 adds Claude Opus 5.5, Sonnet 5.5, and Haiku 5.5;
  Bedrock Converse 0.15.5 adds Opus 5.5 (no forced `toolChoice`), Sonnet 5.5, Haiku 5.5,
  and GPT-6 Sol, Luna, and Astra; `llms-openai` 0.8.4 adds GPT-6 Astra, Sol, Luna, and
  GPT-6.1 Sol and allows openai 3.x.
- **Other:** Google GenAI applies its default temperature only to pre-Gemini-3 models;
  the AG-UI integration moves to protocol 1.0; a langchain-community import fix.
- No deprecations listed. Upgrade with `pip install -U llama-index-core` plus the
  integration packages you use.

## Why it matters

It confirms LlamaIndex is maintained but moving slowly: releases are now about two months
apart and mostly keep integrations current rather than adding framework features.
