## Summary

Codex CLI 0.168.0 (2026-11-13) adds side conversations shown beside the main chat, a model
provider browser in the TUI, audio recording attachments, animated GIF generation, and
terminal notifications with longer command previews. 0.169.0 followed the same day with no
release notes.

## Key points

- **Side conversations:** set `features.tui_workspace` to show a side conversation in a
  pane beside the main chat; drag the divider to resize, `leader z` zooms a pane.
- **Model providers:** browse them under Sessions → Model providers and choose the
  default for new chats; existing chats keep their saved provider.
- **Audio:** attach recordings when using an audio-capable model.
- **Animated GIFs:** `features.image_generation_animation` lets image generation create or
  edit animated GIFs.
- **Notifications:** `tui.notification_method = "osc777"` sends terminal notifications;
  approval notices show longer command previews and separate input from network requests.
- **tmux:** image previews work in fullscreen on Ghostty or Kitty when tmux sets
  `allow-passthrough all`.
- **Deprecation:** setting `features.multi_agent` now warns; use `agents.enabled` to turn
  off subagent tools.
- Upgrade with your usual method (for example `npm i -g @openai/codex`).

## Why it matters

Side conversations let you ask a quick question without derailing the main task, which
Claude Code offers as `/btw`. The provider browser makes non-OpenAI backends easier to use.
