## Summary

Claude Code 2.1.304 adds a guided `/auto-mode-setup` command, review depth levels for
Claude Code Review, and a way for permission mods to insist on a human decision. It also
warns Pro and Max users before an expensive resume, changes how skills and hooks behave
after compaction, and fixes 43 bugs.

## Key points

- **`/auto-mode-setup`:** run it in a project to have Claude read the repo and recent
  sessions and teach auto mode's classifier about your environment, so fewer safe
  actions get blocked. It also works on Bedrock, Vertex, Foundry, the Claude apps
  gateway, and with telemetry off.
- **Code Review levels:** in Code Review admin settings, owners choose Quick, Standard
  (default), or Deep for the organization and can override per repository. A new option
  reviews every repository in the GitHub organization, including ones added later.
- **Human-only approval in mods:** a `tool.check` answer can set `decider: "person"`, so
  only the permission dialog or the host's callback can approve the call. With no one to
  ask (for example `claude -p`), the call is refused with the mod's reason. A new
  `e.isReadOnly` flag tells the mod whether the call is read-only.
- **Managed settings ceilings:** `settings.read` hooks now see each settings layer and can
  rewrite the merged result, so an organization mod can cap values such as
  `cleanupPeriodDays`.
- **`/claude-api managed-agents-secure`:** checks a Managed Agents agent's configuration
  against Anthropic's security guide without changing it.
- **Skills:** the full skill list is resent after compaction, and `/reload-skills` sends
  only new or changed skills. One source can register at most 1,024 skill hooks per
  session.
- **Usage warning:** on Pro and Max, resuming a long-idle conversation that would use a
  large share of the 5-hour limit now asks whether to resume or start fresh.
- **Gateways:** tool search is on by default behind a custom `ANTHROPIC_BASE_URL`, with
  an automatic retry without it if the gateway returns 400 or 422.
- **Cloud sessions:** they no longer wait for a plugin's stdio MCP servers to start
  unless the server sets `alwaysLoad: true`.
- The `/fast` dialog drops the "research preview" label for Opus 5.5 (see the fast mode
  docs).

## Why it matters

`/auto-mode-setup` is the quickest way to make auto mode useful in a specific repo, and
`decider: "person"` lets a team's guardrail mod keep a human in the loop for risky
actions even when auto mode is on. Review levels let teams trade review cost against
depth per repository.
