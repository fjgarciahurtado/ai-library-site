## Summary

Anthropic's reference page for current Claude models: model IDs, context windows,
output limits, and API prices. Figures below were captured on 2026-10-04 from a
reference dated 2026-09-25.

## Key points

- Claude Fable 5.1 (`claude-fable-5-1`): most capable widely released model; 1M context,
  128K output; $10 / $50 per million input / output tokens.
- Claude Opus 5.5 (`claude-opus-5-5`): current Opus; 1M context, 128K output; $4 / $20.
- Claude Sonnet 5.5 (`claude-sonnet-5-5`): current Sonnet; 1M context, 128K output; $2 / $10.
- Claude Haiku 4.5 (`claude-haiku-4-5`): smallest current model; 200K context; $1 / $5.
- Claude Mythos 5.1 is limited to Anthropic's Project Glasswing programme.
- The Models API (`GET /v1/models`) returns live context window, output cap, and capabilities.

## Why it matters

Primary source for Claude model facts; prices and lineups change, so check it before
relying on the numbers above.
