## Summary

Minor release of Pydantic AI, the typed Python agent framework, now on a 2.x line with
near-daily minor releases. This release mainly improves its `clai2` terminal agent and
OpenAI live (realtime) model support. The note also records the recent minor releases,
which add sandboxed workspaces and plugins.

## Key points

- v2.54.0 (2026-10-02): theme-aware file diffs, `/update` self-update with session
  resume, and a double-Esc rewind menu in `clai2`; reconnecting dropped OpenAI Live
  sessions; web search on GPT-Live through delegated backends; a run now ends when a
  background tool raises an unexpected exception.
- v2.53.0 (2026-10-01): security fix for streamed requests in `ConcurrencyLimitedModel`;
  declarative plugins for `clai2`.
- v2.52.0 (2026-09-29): workspaces with one file and command API across local and
  sandbox environments; sandbox backends include Sprites, E2B, SSH, and Bubblewrap.
- v2.51.0 (2026-09-25): `OpenAILiveModel` for OpenAI GPT-Live.

## Why it matters

Pydantic AI has grown from a typed agent library into a fuller agent runtime with its own
CLI agent and sandboxing, overlapping with coding-agent tools.
