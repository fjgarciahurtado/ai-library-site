# AI digest: 2026-10-23

## Highlights

- **MCPtoCodeMode:** a new MIT MCP server that puts all your MCP servers behind three
  tools (`search`, `describe`, `execute`), so the agent chains calls in sandboxed
  JavaScript. Try it with `claude mcp add codemode -- npx -y mcptocodemode serve`.
- **Claude Code 2.1.309:** closes several sandbox gaps (shell startup files ran
  unsandboxed, the `--mcp-config` file could be edited). `sed -i` now gets a normal
  prompt, and `claude ultrareview` scripts need `--trust-workspace`.
- **Agent Skills goes to the Agentic AI Foundation:** the skills standard now has the
  same neutral, Linux Foundation governance as MCP. Anthropic counts over 70 platforms
  that support it.
