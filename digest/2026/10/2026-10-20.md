# AI digest: 2026-10-20

## Highlights

- **Claude Code 2.1.304:** run `/auto-mode-setup` to teach auto mode about a project,
  choose Quick, Standard, or Deep levels in Code Review, and use `decider: "person"` to
  make a permission mod require a human decision.
- **Graphicle:** a new local MCP server (Rust, Apache-2.0, pre-release) that gives coding
  agents a code graph and memory of past sessions. Install with `brew install
  graphicle-ai/tap/graphicle`, then run `graphicle setup`.
- **Opus 5.5 fast mode is GA:** set `speed: "fast"` with no beta header, at $8 / $40 per
  1M tokens.
