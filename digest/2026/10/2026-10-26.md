# AI digest: 2026-10-26

## Highlights

- **Context Mode:** an MCP server and Claude Code plugin that keeps large tool output
  (logs, test runs, web pages) in a sandbox and returns only what the code prints. It
  also saves session events so work state survives compaction. Try it with
  `/plugin marketplace add mksglu/context-mode`, then
  `/plugin install context-mode@context-mode`.
- **VS Code 1.143:** run one task with several models, let a judge model pick the best
  result or merge them (`sessions.chat.compareAgents.enabled`). The Copilot harness is
  now the default for new sessions.
- **Codex CLI 0.164 presets:** `/presets` saves prompts, slash commands, and permission
  settings in ten slots, and `/model` takes model, effort, and speed inline.
