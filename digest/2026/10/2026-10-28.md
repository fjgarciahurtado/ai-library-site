# AI digest: 2026-10-28

## Highlights

- **Gemini API CLI (`gemini-api`) beta:** a dependency-free binary that lets any coding
  agent generate images, speech, and video, analyse files, or start a Deep Research job
  with one shell command, with `-o json` and `--dry-run` built for agents.
- **Claude Code 2.1.312:** Write no longer overwrites a large CLAUDE.md it has only
  partly read, `paths:` skills work after a `cd`, and prompt and agent hooks are capped
  at 24 concurrent per session.
- **Two skill packs to try:** BeautifulRust (write, review, and port idiomatic Rust,
  installable as a Claude Code plugin) and Archify (interactive HTML diagrams of a plan
  or codebase).
