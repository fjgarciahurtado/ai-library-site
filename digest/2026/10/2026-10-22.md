# AI digest: 2026-10-22

## Highlights

- **stalemap:** a new MIT plugin and MCP server that tells your coding agent which npm
  dependencies changed after its training cutoff. Install with
  `/plugin marketplace add Umair/stalemap`, then `/plugin install stalemap@stalemap`.
- **Claude Code 2.1.307:** `/claude-api api-version` migrates your Claude API code to the
  new API version. A `claude_code.safety_event` OpenTelemetry event records every blocked
  or prompted tool call, and `@claude review stop` ends always-on Code Review.
- **Claude API version 2026-10-21:** new SDK majors (Python 2.0, TypeScript 1.0, and
  others) remove `temperature`, `top_p`, and `top_k`, send keys as
  `Authorization: Bearer`, and switch to Apache 2.0. Check your code and gateways
  before upgrading.
