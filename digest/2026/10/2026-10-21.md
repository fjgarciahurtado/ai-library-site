# AI digest: 2026-10-21

## Highlights

- **Claude Code 2.1.305:** upgrade if you use Bedrock, Vertex, or a gateway, because it
  fixes a 2.1.304 regression that broke every request there. It also adds
  `sandbox.allowNestedUserNamespaces` for Chromium and podman inside the Linux sandbox,
  and a `/usage` view where `f` applies the fixes it suggests.
- **Dashboard Design skill:** a new MIT skill and plugin for building and critiquing
  analytics dashboards. Install it with
  `/plugin marketplace add abdiraimov-otabek/dashboard-design-skill`.
- **OpenAI 12-hour prompt cache:** `prompt_cache_options.ttl: "12h"` keeps a prefix warm
  for a whole day, at 2.5x input to write. Gap filled: Ultrafast costs 6x Standard.
