# AI digest: 2026-10-27

## Highlights

- **Claude Code 2.1.311:** type `ultrathink` to run a single turn at `xhigh` effort.
  Standard-context sessions now compact instead of stopping at 200K tokens, and
  subagents can use MCP servers that connect late.
- **Copilot assisted permissions are GA:** a model approves safe commands in Copilot
  CLI, the Copilot app, and VS Code (`/permissions` → assisted). It is GitHub's
  counterpart to Claude Code's auto mode.
- **GPT-6.1 Terra:** a mid-priced OpenAI model for computer use and vision at $1 / $5
  per 1M tokens, half the price of Sol.
