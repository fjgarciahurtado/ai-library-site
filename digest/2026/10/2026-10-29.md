# AI digest: 2026-10-29

## Highlights

- **GitHub Agentic Workflows GA:** write a repo chore as a Markdown file, and `gh aw`
  compiles it into an Actions job that runs Copilot, Claude, Codex, Gemini, or Pi in a
  read-only sandbox with "safe outputs" (`gh extension install github/gh-aw`).
- **Copilot connectors and Agent Merge:** 26 GitHub-verified MCP servers (Slack, Sentry,
  Linear, Figma…) you sign in to once across Copilot clients, and a **Watch and fix**
  button that lets Copilot fix failing checks and merge conflicts on a PR.
- **Two skill packs to try:** Addy Osmani's agent-skills (25 spec-to-ship skills,
  installable as a Claude Code or Codex plugin) and MiniMax's mcode-stack (its agent
  team's own skills for long sessions and context).
