# AI digest: 2026-10-16

## Highlights

- **METR embedded at Anthropic:** six METR staff get employee-like internal access and
  can publish without Anthropic's approval. Anthropic can only redact three fixed
  categories. A three-tier scheme now defines how much access evaluators get.
- **Mistral Timestral:** four open time-series forecasting models (5M–209M, Modified
  MIT) that run zero-shot on a CPU. Mistral says they top the GIFT-Eval, TIME, and
  fev-bench leaderboards for zero-shot models.
- **GPT-Live meets Decisions:** OpenAI's voice model can now call the Decisions API
  mid-utterance (changelog entry, noted on the GPT page; no separate source note because
  that URL is already in the library).
