# AI digest: 2026-10-15

## Highlights

- **Claude Code idle compaction:** 2.1.299 compacts 200K+ token conversations after
  about 54 idle minutes, before the one-hour prompt cache expires, to avoid a full
  uncached re-read. Remote MCP connectors now default to the stateless 2026-07-28 spec.
- **Gemini 4 Argon is Stable:** the Gemini API model page labels it Stable, and the
  changelog lists it as GA from 2026-10-13. It supports implicit caching only.
- **Anthropic on the US midterms:** its 5.5 models score 99% on political evenhandedness.
  Red teaming found that campaigns split into harmless-looking subtasks can slip past
  per-request refusals.
