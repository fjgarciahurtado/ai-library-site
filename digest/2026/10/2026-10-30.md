# AI digest: 2026-10-30

## Highlights

- **Claude Code 2.1.314 write fence:** set
  `permissions.blockWritesOutsideWorkingDirectories: true` and Write/Edit refuse paths
  outside the repo in every mode, bypass included. Idle compaction in VS Code and the
  Desktop Code tab makes returning to a long session cheaper.
- **Two memory tools to try:** claude-mem captures sessions and feeds summaries back
  into later ones (`/plugin marketplace add thedotmack/claude-mem`), and
  codebase-memory-mcp gives agents a local graph of code, docs, and infrastructure.
- **Know who is spending:** Anthropic's Usage and Cost Analytics API (beta) breaks
  cost down by key, model, workspace, and user, in buckets as fine as one minute.
