# AI digest: 2026-11-12

## Highlights

- **Update `mcp-server-git` now.** Versions before 2026.11.11 run commands from a
  repository's own `.git/config`, even on read-only calls such as `git_status`, with no
  prompt (High). Fixes for the filesystem and fetch servers shipped the same day.
- **Ponytail** is a plugin that makes coding agents write the smallest change that works.
  Install with `/plugin marketplace add DietrichGebert/ponytail`, then
  `/plugin install ponytail@ponytail`. Its star count looks inflated, so read the skill
  before relying on it.
- **Gemini Decisions API** (`gemini-decision-1`) returns calibrated yes/no, choice, and
  rubric scores over text, images, audio, video, and PDFs at $0.10 per 1M input tokens,
  with no output charge.
