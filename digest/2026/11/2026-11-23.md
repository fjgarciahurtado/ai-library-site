# AI digest: 2026-11-23

## Highlights

- **fast-anything** profiles an app and has your coding agent port only the hot
  functions to Rust, verified by replaying recorded calls. It installs as a Claude Code
  plugin, an MCP server, or a skill.
- **Claude Code 2.1.330** lets `/loop` and scheduled tasks run for 30 days (was 7) and
  adds Easel, a built-in mod that draws charts in the session.
- **Kimi K3.1 Pro weights** are out: a 2.8T / 104B-active MoE under an MIT-style licence
  with conditions for large API hosts.
