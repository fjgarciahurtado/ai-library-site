# AI digest: 2026-11-25

## Highlights

- **Claude Code 2.1.332** lets MCP servers serve skills (beta, shown as `server:skill`)
  and adds a `PreSkillShellCommand` hook to vet shell commands that skills run.
- **Claude Security plugin 0.13.0**: multi-agent vulnerability scans with verified
  findings, now with attack surface analysis and a live view.
  `/plugin install claude-security@claude-plugins-official`.
- **Apify MCP server**: thousands of maintained scrapers for agents in one hosted MCP
  server (`claude mcp add apify "https://mcp.apify.com" -t http`).
