# AI digest: 2026-11-02

## Highlights

- **Claude Code 2.1.316:** `CLAUDE_CODE_SUBAGENT_EFFORT` lets subagents run at a lower
  effort than the main session, a direct cost lever for multi-agent work.
- **Gemini Computer Use is GA** (2026-10-30) on Argon, 3.8 Flash, and the cheap 3.5
  Flash-Lite, for browser, desktop, and mobile automation run by your own client.
- **Fast mode on Opus 4.8 ends on 2026-11-30.** Fast requests will fail, so move them
  to Opus 5.5.
