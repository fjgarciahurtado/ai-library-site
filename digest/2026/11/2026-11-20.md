# AI digest: 2026-11-20

## Highlights

- **Claude Code 2.1.329:** `/tasks` now shows and stops scheduled tasks, `/loop`
  wakeups, and forks. `/code-review` reviews the whole branch by default. If a
  PreToolUse hook guards Code Mode, add `"onFailure": "block"` to it.
- **rust-anything:** a new MCP server and skill that let a coding agent port code to
  Rust one unit at a time, checking each unit by replaying recorded behaviour
  (`cargo install rust-anything && rust-anything setup`).
- **Deferred tool loading spreads:** the Gemini API added tool retrieval (preview),
  including for remote MCP servers, and Pydantic AI added `ToolBridge`.
