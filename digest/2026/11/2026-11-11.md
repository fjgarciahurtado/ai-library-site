# AI digest: 2026-11-11

## Highlights

- **Scrapling MCP server** gives your agent a browser-grade scraper with saved logins,
  screenshots, and network inspection. It strips hidden prompt-injection text by default.
  Install with `pip install "scrapling[ai]"`, then
  `claude mcp add ScraplingServer "$(which scrapling-mcp)"`.
- **Context7** gives coding agents current, version-specific library docs on demand.
  Set it up with `npx ctx7 setup --claude`, which installs a skill and CLI; no MCP server
  is needed.
- **Gemini 4 Carbon** is generally available. It is Google's strongest model and costs
  the same as Argon ($2 / $10) until 2026-11-30, then $4 / $20.
