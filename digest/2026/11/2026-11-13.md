# AI digest: 2026-11-13

## Highlights

- **Claude Code 2.1.323** adds Code Mode, an experimental opt-in where Claude writes
  JavaScript to call its tools. It also adds plugin version ranges and fixes several
  permission gaps, including wildcard Bash allow rules that skipped prompts. Update with
  `claude update`. The Code Mode docs page was still a 404 today.
- **lot-map** is a plugin that shows a live map of tool calls, hooks, skills, and
  subagents beside the chat: `claude plugin marketplace add alexeyw/lot-map`, then
  `claude plugin install lot-map@lot-map`.
- **Gemini 4 Hydrogen** is the cheap, fast Gemini 4 model at $1.50 / $7.50 per 1M tokens,
  with a new `xhigh` thinking level. Google pitches it as the replacement for 3.8 Flash.
