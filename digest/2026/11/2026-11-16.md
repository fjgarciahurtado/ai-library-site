# AI digest: 2026-11-16

## Highlights

- **Claude Code Code Mode can now be tried:** the docs page is live. Start Claude Code
  with `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` (interactive terminal only, 5.5 models or
  Fable 5.2) and Claude writes JavaScript that makes several tool calls at once.
- **Claude Code 2.1.325 changes permission defaults:** sandboxed Bash prompts again
  unless `sandbox.autoAllowBashIfSandboxed: true`, and scheduled tasks or `/loop` need a
  `Skill(name)` allow rule to run skills that declare tools or hooks.
- **craft:** a new design-process skill pack (brief, every screen state, critique):
  `/plugin marketplace add diego3g/craft`, then `/plugin install craft@craft`.
