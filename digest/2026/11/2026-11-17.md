# AI digest: 2026-11-17

## Highlights

- **Open Code Review (Alibaba):** a free AI code review CLI and skill set. Try
  `npx skills add alibaba/open-code-review`; its delegation mode lets your coding agent
  do the review with OCR's file selection and rules, with no extra API key.
- **Claude Code 2.1.326:** Code Mode now works with agent teams, and incomplete tool
  rules, malformed plugin fields, and unsaved settings now produce warnings.
- **VS Code drops the Local harness in February 2027:** move Copilot sessions to the
  Copilot harness (**Session Target → Copilot**). VS Code 1.146 also lets the agent run
  model comparisons itself and adds an inbox across workspaces.
