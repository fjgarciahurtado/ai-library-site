# AI digest: 2026-11-09

## Highlights

- **Claude Code 2.1.319** runs MCP tasks in the background, adds
  `permissions.denyInsteadOfPrompting` for unattended runs and
  `/claude-api latency-optimize`, and fixes several permission bypasses. Upgrade if you
  use auto or accept-edits mode.
- **Anthropic's "The components of agent memory"** gives measured advice. Tell strong
  models what memory is for rather than rules about what to save, keep the startup
  context small, and run a "dreaming" pass that corrects notes against transcripts.
- **sandbox-mcp** gives agents a throwaway Windows 11 machine to deploy, drive, and test
  apps in (Windows Pro or Enterprise only).
