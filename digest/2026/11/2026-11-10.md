# AI digest: 2026-11-10

## Highlights

- **Claude Code 2.1.321** makes Claude Fable 5.2 the default Fable model, adds
  `claude remote-control --settings <file>`, and fixes an MCP OAuth token leak and
  several permission gaps. 2.1.322 adds fast mode on Vertex AI. Upgrade now.
- **Taste Skill** is a design skill for company websites. It picks palette, fonts, and
  layout for the client's business and checks the page in headless Chrome. Install with
  `/plugin marketplace add Leonxlnx/taste-skill`.
- **Claude Fable 5.2 and Mythos 5.2** cost $8 / $40, 20% less than 5.1, with large
  agentic-coding gains (vendor figures). Before switching API code, check the new
  thinking prefix check, the account-bound thinking, and the new computer-use toolset.
