# AI digest: 2026-11-04

## Highlights

- **Skills as locked dependencies (APM and Dependabot):** Microsoft's APM declares
  skills, prompts, and MCP servers in `apm.yml`, installs them into Claude Code, Codex,
  Copilot, and others with `apm install`, and pins them in a lockfile. Dependabot now
  opens update PRs for it.
- **Impeccable:** 24 design commands for coding agents (`/impeccable critique`, `polish`,
  `audit`) plus a no-LLM "AI slop" detector. Install with `npx impeccable install`.
- **Claude Code 2.1.318:** unattended runs can see when a claude.ai sign-in ends
  (`credential_expires_at`, a stderr warning from 10 days before), plus many headless
  fixes.
