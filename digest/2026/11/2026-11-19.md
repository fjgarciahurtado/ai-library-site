# AI digest: 2026-11-19

## Highlights

- **`gh event listen` (GitHub CLI 2.105.0, preview):** a coding agent can wait for a PR
  review, CI result, or merge conflict with one command instead of polling. Needs
  Event Streams access (waitlist).
- **Claude Code 2.1.328:** `"onFailure": "block"` makes `mcp_tool` hooks fail closed;
  fixes for scheduled tasks being erased and zsh commands containing `=` words.
- **Copilot plugins and connectors:** team plugin defaults are GA on Business and
  Enterprise, and eight new MCP connectors (Supabase, Buildkite, Box, and more) are in
  preview. Gemini 4 Neon ($3 / $15) is GA between Hydrogen and Carbon.
