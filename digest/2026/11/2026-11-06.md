# AI digest: 2026-11-06

## Highlights

- **Apple's Xcode plugin for Claude Code:** build, test, SwiftUI previews, simulators,
  and Apple docs over MCP. Install with
  `claude plugin install xcode@claude-plugins-official` on a Mac with Xcode.
- **Champion Kit:** Anthropic's plugin for spreading Claude Code in a team;
  `/champion-kit:patterns` also finds skill candidates in your own repo.
- **Floorplan:** a Claude Code and Codex plugin that draws a plain-English map of a
  codebase and of what the agent just changed.
