# AI digest: 2026-11-24

## Highlights

- **Claude Code 2.1.331** adds an API check to `claude doctor`, a switch for proxies that
  cut off compressed responses, and `optionalDependencies` for plugins. Managed
  marketplaces will auto-update by default from 2026-11-30.
- **Codex CLI 0.172.0** starts optional MCP servers only on their first tool call and
  adds per-tool approval for app tools.
- **Opus 4.5 is deprecated** and retires on 2027-01-22 (Sonnet 4.5 goes on 2026-11-30).
  Haiku 4.5 still has no deprecation date.
