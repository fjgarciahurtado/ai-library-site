# AI digest: 2026-11-03

## Highlights

- **Google's Elephant-Goldfish Model plugin:** design-before-code skills where fresh,
  context-free subagents review your agent's design doc. Install in Claude Code with
  `claude plugin marketplace add google/elephant-goldfish-model`, then
  `claude plugin install egm@egm`.
- **Claude message threads (beta):** long agent loops send only new messages each turn
  for a lower time to first token. Prices are unchanged.
- **Gemini 2.5 Pro and 2.5 Flash deprecated:** from 2026-12-01 they route to 3.8 Flash
  and 3.5 Flash-Lite at the new models' prices, with breaking API changes.
