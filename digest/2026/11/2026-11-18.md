# AI digest: 2026-11-18

## Highlights

- **External sandboxes for coding agents (Prime Radiant):** run Claude Code's Bash,
  Codex, or Pi commands in a throwaway Linux VM that sees only the folders and hosts you
  allow, with API keys swapped in by a proxy. Start with
  `npx --yes external-sandbox-v86 --mount-rw "project=$PWD"`. Experimental.
- **GitHub Copilot at Ignite:** browser use in your signed-in Chrome (CLI, app, VS Code,
  JetBrains), Copilot Evals (`/eval`) to test skills, agents, and MCP tools, on-demand
  secret scanning through `/security-review`, and adaptive-effort code review.
- **Claude Code 2.1.327:** `claude mcp add-json <name> -` keeps MCP tokens out of shell
  history, and `/status` now lists broken skills, agents, and hook matchers.
