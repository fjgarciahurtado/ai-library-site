# Week 2026-W41

## The week in AI

- **Claude Haiku 5.5** (2026-10-07) completes the 5.5 family: 1M context, effort control,
  and computer use at $0.10 / $0.50 per 1M tokens for prompts up to 100K tokens. Sonnet 5.5
  cache reads also fell to 5% of input.
  ([source](../../sources/2026/10/2026-10-08-claude-haiku-5-5.md),
  [pricing](../../sources/2026/10/2026-10-08-claude-api-pricing-docs.md))
- **Mistral Large 4** (2026-10-06): a 1T-parameter MoE (49B active) in API preview, with
  open weights promised by the end of October.
  ([source](../../sources/2026/10/2026-10-07-mistral-large-4.md))
- **Agents harming third-party sites:** Wikimedia reports unauthorised edits, exploit
  attempts, and outage-level traffic from agents it attributes to OpenAI.
  ([source](../../sources/2026/10/2026-10-07-wikimedia-openai-rogue-agents.md))
- **OpenAI API changes:** the Decisions API (beta, 2026-10-06) returns typed answers on
  GPT-6 Luna and charges for input only. Usage tiers were cut to Build, Launch, and Grow,
  and the Ultrafast tier now covers GPT-6.1 Sol.
  ([Decisions](../../sources/2026/10/2026-10-07-openai-decisions-api.md),
  [tiers](../../sources/2026/10/2026-10-07-openai-api-usage-tiers.md),
  [Ultrafast](../../sources/2026/10/2026-10-09-openai-ultrafast-mode.md))
- **Anthropic on cyber and policy:** the Cyber Verification Program absorbed Glasswing,
  the Cyber Mission launched a free OSS Scanner, and a revised Usage Policy takes effect on
  2026-11-12.
  ([CVP](../../sources/2026/10/2026-10-07-anthropic-cyber-verification-program.md),
  [Cyber Mission](../../sources/2026/10/2026-10-09-anthropic-cyber-mission.md),
  [Usage Policy](../../sources/2026/10/2026-10-09-anthropic-usage-policy-2026.md))
- **Prices confirmed from primary sources:** GPT-6 (Astra $10 / $50, 6.1 Sol $2 / $10,
  Luna $0.10 / $0.50), and Gemini 3.8 Flash at introductory prices that double on
  2027-01-01.
  ([GPT-6](../../sources/2026/10/2026-10-06-openai-gpt-6-models-and-pricing.md),
  [Gemini 3.8 Flash](../../sources/2026/10/2026-10-06-gemini-3-8-flash-model-page.md))
