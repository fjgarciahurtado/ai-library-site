# Week 2026-W44

## The week in AI

- **Coding agents as CI jobs:** [GitHub Agentic Workflows](../../sources/2026/10/2026-10-29-github-agentic-workflows-ga.md)
  is GA. A Markdown file becomes an Actions job that runs Copilot, Claude, Codex, Gemini,
  or Pi in a read-only sandbox, and it can write only through declared "safe outputs".
  At the same GitHub Universe event, [Copilot connectors](../../sources/2026/10/2026-10-29-copilot-connectors-verified-mcp.md)
  added 26 verified MCP servers and [Agent Merge](../../sources/2026/10/2026-10-29-copilot-agent-merge-pull-requests.md)
  fixes failing checks on a PR.
- **A hard write fence for Claude Code:** [2.1.314](../../sources/2026/10/2026-10-30-claude-code-2-1-314.md)
  adds `permissions.blockWritesOutsideWorkingDirectories`, which holds in every mode,
  bypass included. Earlier in the week, [2.1.311](../../sources/2026/10/2026-10-27-claude-code-2-1-311.md)
  added `ultrathink` for a single `xhigh` turn and compaction past 200K tokens.
- **Multi-model routing goes mainstream:** [Copilot Fusion](../../sources/2026/10/2026-10-29-github-copilot-fusion-ga.md)
  routes each prompt to a single model, a cascade, or a critique loop. GitHub claims it
  is close to Claude Code with Opus 5.5 at half the cost (vendor figures). VS Code 1.143
  [compares and merges](../../sources/2026/10/2026-10-26-vscode-1-143-compare-models.md)
  results from several models.
- **Gemini from the shell:** the [`gemini-api` CLI](../../sources/2026/10/2026-10-28-gemini-api-cli-beta.md)
  (beta) lets any agent generate media, analyse files, or start Deep Research with one
  command, with `-o json` and `--dry-run`.
- **Know who is spending:** Anthropic's [Usage and Cost Analytics API](../../sources/2026/10/2026-10-30-claude-usage-cost-analytics-api.md)
  (beta) breaks cost down by key, model, workspace, and user.
- **Models:** OpenAI's [GPT-6.1 Terra](../../sources/2026/10/2026-10-27-gpt-6-1-terra.md)
  ($1 / $5) targets computer use. [Kimi K3.1 Pro](../../sources/2026/10/2026-10-26-kimi-k3-1-pro.md)
  comes close to Opus 5.5 on Moonshot's own figures, with weights promised by 2026-11-04.
  [Mistral Large 4](../../sources/2026/11/2026-11-01-mistral-large-4-model-card.md)
  weights are now public, under a licence that restricts model-as-a-service use.

## Rising on GitHub

- [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
  (54,581 stars, +479 this week): lets a coding agent drive and inspect a live Chrome
  for debugging and performance traces. Apache-2.0; install with
  `/plugin marketplace add ChromeDevTools/chrome-devtools-mcp`. Usage statistics are on
  by default (`--no-usage-statistics`).
- [upstash/context7](https://github.com/upstash/context7) (64,033 stars, +405): current,
  version-specific library docs for agents through an MCP server or the `ctx7` CLI
  (`npx ctx7 setup --claude`). The docs are community-contributed, so they can be wrong.
- [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) (108,183 stars,
  +5,290; [in library](../../sources/2026/10/2026-10-30-claude-mem-persistent-agent-memory.md)):
  automatic memory across sessions for Claude Code, Codex, and others.
- [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) (181,666 stars,
  +5,998): a MIT skill and plugin that pushes agents to write the least code a task
  needs, with `/ponytail-review` and `/ponytail-audit`. Its benchmarks are self-reported
  and the star count is unusually high for a new repo.
- [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (107,230 stars,
  +5,107): a MIT front-end design skill that gives the agent an art direction, real
  photos, and a browser check of its own output
  (`npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"`).
  The README is promotional, and the star count could not be verified.
