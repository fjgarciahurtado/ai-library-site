# Week 2026-W47

## The week in AI

- **Claude Code Code Mode can now be tried.** Start Claude Code with
  `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` (interactive terminal only, 5.5 models or Fable
  5.2) and Claude writes JavaScript that makes several tool calls at once. From 2.1.329,
  a `PreToolUse` hook that guards it needs `"onFailure": "block"` to stay fail-closed.
  ([docs](../../sources/2026/11/2026-11-16-claude-code-code-mode-docs.md),
  [2.1.329](../../sources/2026/11/2026-11-20-claude-code-2-1-329.md))
- **Claude Code 2.1.325 to 2.1.329 tightened defaults and added background-task
  controls.** Sandboxed Bash prompts again unless `sandbox.autoAllowBashIfSandboxed` is
  on, and scheduled tasks need a `Skill(name)` rule to run skills that declare tools or
  hooks. `claude mcp add-json` keeps tokens out of shell history, `/status` lists broken
  customizations, and `/tasks` stops scheduled tasks and `/loop` wakeups.
  ([2.1.325](../../sources/2026/11/2026-11-16-claude-code-2-1-325.md),
  [2.1.327](../../sources/2026/11/2026-11-18-claude-code-2-1-327.md))
- **GitHub Copilot at Ignite:** browser use in your signed-in Chrome, Copilot Evals
  (`/eval`) to test skills, agents, and MCP tools, on-demand secret scanning, adaptive
  code review, team plugin defaults (GA), and eight new MCP connectors.
  ([Evals](../../sources/2026/11/2026-11-18-github-copilot-evals-preview.md),
  [browser use](../../sources/2026/11/2026-11-18-copilot-browser-use.md),
  [team plugins](../../sources/2026/11/2026-11-19-copilot-team-plugin-defaults.md))
- **External sandboxes for coding agents (Prime Radiant, experimental):** run Claude
  Code's Bash, Codex, or Pi commands in a throwaway Linux VM that sees only the folders
  and hosts you allow, with API keys swapped in by a proxy.
  ([source](../../sources/2026/11/2026-11-18-external-sandboxes-coding-agents.md))
- **New models and prices:** GPT-6.2 Astra (20% cheaper) and Sol, plus 30–40% off for
  2–8 hour background windows; Gemini 4 Neon is GA at $3 / $15 with `high` thinking by
  default. Reminder: Gemini 4 Carbon and Argon double to $4 / $20 after 2026-11-30, the
  same day fast mode on Opus 4.8 stops working.
  ([GPT-6.2](../../sources/2026/11/2026-11-18-gpt-6-2-astra-sol.md),
  [Neon](../../sources/2026/11/2026-11-19-gemini-4-neon.md))
- **Deferred tool loading is spreading:** the Gemini API added tool retrieval
  (preview), including for remote MCP servers, and Pydantic AI added `ToolBridge`.
  ([Gemini](../../sources/2026/11/2026-11-20-gemini-api-tool-retrieval-preview.md),
  [Pydantic AI](../../sources/2026/11/2026-11-20-pydantic-ai-v2-71.md))

## Rising on GitHub

- [alibaba/open-code-review](https://github.com/alibaba/open-code-review) (about 55,200
  stars, +3,600 this week): free AI code review as a CLI or skills; its delegation mode
  lets your own coding agent do the review (`npx skills add alibaba/open-code-review`).
- [erkamyaman/rust-anything](https://github.com/erkamyaman/rust-anything) (about 7,600
  stars in 6 days): MCP server and skill for porting code to Rust one unit at a time,
  each checked against recorded behaviour.
- [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design) (about
  69,900 stars, +2,700 this week; star count unverified): skill that turns a request
  or an existing Mermaid, draw.io, or PlantUML file into a self-contained HTML/SVG
  diagram (`/plugin marketplace add cathrynlavery/diagram-design`). MIT.
- [apify/apify-mcp-server](https://github.com/apify/apify-mcp-server) (about 17,300
  stars, +1,000 this week): Apify's official MCP server for running ready-made scrapers
  (search, maps, social media) and getting structured results
  (`claude mcp add apify "https://mcp.apify.com" -t http`). MIT; Apify runs are paid.
- [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
  (about 58,700 stars, +2,300 this week): lets an agent check pages with performance
  traces, console, network, and screenshots.
