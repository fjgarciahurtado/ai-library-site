# Week 2026-W43

## The week in AI

- **Agent Skills gets neutral governance:** Anthropic donated the spec, name, and
  agentskills.io to the Agentic AI Foundation (Linux Foundation), which also governs MCP.
  Maintainers from Anthropic, Google, OpenAI, and others now steer it, and Anthropic counts
  over 70 platforms that load skills.
  ([source](../../sources/2026/10/2026-10-23-agent-skills-donated-to-aaif.md))
- **Code mode for any MCP server:** MCPtoCodeMode (MIT) hides all your MCP servers
  behind `search`, `describe`, and `execute`, and runs the model's JavaScript in a QuickJS
  sandbox. Add it with `claude mcp add codemode -- npx -y mcptocodemode serve`.
  ([source](../../sources/2026/10/2026-10-23-mcptocodemode-mcp-code-mode-proxy.md))
- **Claude API version `2026-10-21`:** the first new API version since `2023-06-01`.
  It removes `temperature`, `top_p`, and `top_k` (400 on every model), and the new SDK
  majors send keys as `Authorization: Bearer` and move to Apache 2.0. Claude Code's
  `/claude-api api-version` migrates code.
  ([migration guide](../../sources/2026/10/2026-10-22-claude-api-version-2026-10-21.md),
  [2.1.307](../../sources/2026/10/2026-10-22-claude-code-2-1-307.md))
- **Claude Code sandbox hardening:** 2.1.309 closes gaps where shell startup files ran
  unsandboxed and sandboxed commands could edit the `--mcp-config` file. If you use
  Bedrock, Vertex, or a gateway, skip 2.1.304: it broke every request there, and 2.1.305
  fixes it.
  ([2.1.308–309](../../sources/2026/10/2026-10-23-claude-code-2-1-308-309.md),
  [2.1.305–306](../../sources/2026/10/2026-10-21-claude-code-2-1-305-306.md))
- **How Anthropic reviews agent-written code:** every PR gets a multi-agent review with
  voting, human approvals scale with risk, and review is capped at three rounds. Merged
  PRs doubled from June to September 2026 while the reverted share fell by over 40%
  (Anthropic's own figures).
  ([source](../../sources/2026/10/2026-10-19-claude-code-team-code-review.md))
- **Cheaper speed and longer caches:** Opus 5.5 fast mode is GA at $8 / $40 per 1M
  tokens, and OpenAI's Responses API keeps a prompt cache for 12 hours at 2.5x input to
  write. OpenAI's Decisions API also went GA, with up to 400 questions per request.
  ([fast mode](../../sources/2026/10/2026-10-20-claude-opus-5-5-fast-mode-ga.md),
  [12-hour cache](../../sources/2026/10/2026-10-21-openai-12-hour-prompt-caching.md),
  [Decisions](../../sources/2026/10/2026-10-23-openai-decisions-api-ga.md))

## Rising on GitHub

The report's "Rising" lists are still empty (no snapshot is 7 days old yet), so these
come from "New this week". I read each README; all star counts and benchmark claims are
the projects' own.

- [morganlinton/BeautifulRust](https://github.com/morganlinton/BeautifulRust) (308
  stars): MIT skill and plugin, distilled from five Rust style guides, that makes agents
  write idiomatic Rust. Install with `npx skills add morganlinton/BeautifulRust`.
- [EricJujianZou/rederive](https://github.com/EricJujianZou/rederive) (192 stars): MIT
  skill that teaches you a codebase by asking guiding questions, so you work out its
  design decisions yourself. Install with `/plugin marketplace add EricJujianZou/rederive`.
- [rextail-ai/lessloc](https://github.com/rextail-ai/lessloc) (101 stars): Apache-2.0
  plugin that steers Claude Code, Codex, Cursor, and others to the least code that does
  the job. It claims up to 36% less code and 26% lower cost.
- [kanaworksai-hue/audio-studio-mcp](https://github.com/kanaworksai-hue/audio-studio-mcp)
  (481 stars): MIT MCP server that generates background music and sound effects locally
  with Stable Audio 3 (Apple Silicon or NVIDIA). The weights are under the Stability AI
  Community License.
- [tomtomsatnav/agent-orchestration-standard](https://github.com/tomtomsatnav/agent-orchestration-standard)
  (76 stars): MIT, read-only, local dashboard for Claude Code sessions and subagents
  (tokens, cost, file conflicts). It is a macOS-first personal project.
