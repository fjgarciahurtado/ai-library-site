# Week 2026-W45

## The week in AI

- **Skills become locked dependencies:** Microsoft's [APM](../../sources/2026/11/2026-11-04-apm-agent-package-manager.md)
  declares skills, prompts, plugins, and MCP servers in `apm.yml` and pins them in a
  lockfile across Claude Code, Codex, Copilot, and others. [Dependabot](../../sources/2026/11/2026-11-04-dependabot-apm-version-updates.md)
  now opens update PRs for them, so you can review skill updates like any other dependency.
- **Plugins for real work:** Apple's [Xcode plugin](../../sources/2026/11/2026-11-06-apple-xcode-plugin-claude-code.md)
  brings builds, tests, SwiftUI previews, and simulators to Claude Code over MCP.
  Google's [Chrome DevTools MCP](../../sources/2026/11/2026-11-05-chrome-devtools-mcp.md)
  gives agents a live browser with DevTools, and [Elephant-Goldfish Model](../../sources/2026/11/2026-11-03-elephant-goldfish-model-plugin.md)
  uses fresh, context-free subagents to review a design before any code is written.
- **Safer unattended agents:** [Claude Code 2.1.317](../../sources/2026/11/2026-11-03-claude-code-2-1-317.md)
  and the [Agent SDK](../../sources/2026/11/2026-11-03-claude-agent-sdk-python-0-2-177.md)
  let policy hooks fail closed, and [2.1.318](../../sources/2026/11/2026-11-04-claude-code-2-1-318.md)
  warns 10 days before a stored sign-in ends. The Claude Console added a beta
  [IP allowlist](../../sources/2026/11/2026-11-06-claude-console-ip-allowlist.md) for API keys.
- **Cheaper multi-agent runs:** [`CLAUDE_CODE_SUBAGENT_EFFORT`](../../sources/2026/11/2026-11-02-claude-code-2-1-316.md)
  runs subagents at a lower effort than the main session. Claude [message threads](../../sources/2026/11/2026-11-03-claude-message-threads-beta.md)
  (beta) mean long agent loops send only new messages each turn.
- **Deadlines to act on:** fast mode on Opus 4.8 [ends on 2026-11-30](../../sources/2026/11/2026-11-02-opus-4-8-fast-mode-deprecated.md).
  From 2026-12-01, Gemini 2.5 Pro and Flash are [routed to newer models](../../sources/2026/11/2026-11-03-gemini-2-5-pro-flash-deprecation.md)
  at their prices, with breaking API changes.
- **Models:** OpenAI's [GPT-6-Cyber](../../sources/2026/11/2026-11-06-gpt-6-cyber.md)
  ($20 / $100, vetted access only) and [Images 2.6](../../sources/2026/11/2026-11-05-gpt-image-2-6-sunburst-flare.md);
  Gemini [function responses](../../sources/2026/11/2026-11-06-gemini-api-files-in-function-responses.md)
  now carry files, audio, and video.

## Rising on GitHub

- [google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model)
  (14,166 stars, +6,110 this week; [in library](../../sources/2026/11/2026-11-03-elephant-goldfish-model-plugin.md)):
  draft a design doc, then have context-free subagents look for unstated assumptions
  before you build (`claude plugin marketplace add google/elephant-goldfish-model`).
- [haydenschmitty/floorplan](https://github.com/haydenschmitty/floorplan) (3,194 stars,
  +2,193; [in library](../../sources/2026/11/2026-11-06-floorplan-codebase-map-plugin.md)):
  an interactive plain-English map of a codebase and of what the agent just changed,
  useful for reviewing agent work in unfamiliar repos.
- [xerj-org/xerj](https://github.com/xerj-org/xerj) (about 18,600 stars, +606): a Rust
  search engine and MCP server that indexes code, docs, logs, CSV/JSONL, and PDFs for
  keyword, vector, or hybrid search; `xerj init` wires it into Claude Code. Apache-2.0,
  but the release binaries include proprietary components, and its benchmarks are its own.
- [shanselman/sandbox-mcp](https://github.com/shanselman/sandbox-mcp) (290 stars, new):
  MIT MCP server that gives an agent a throwaway Windows Sandbox machine to install and
  click through your app, then discards it. Needs Windows 11 24H2 Pro or higher.
- [D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling) (about 99,400 stars,
  +8,250): BSD-3 Python scraping framework with an MCP server
  (`pip install "scrapling[ai]"`) for agents that extract data from sites. Its
  anti-detection browsers bypass bot protection, so check each site's terms before you
  use them.
